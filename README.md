# صفحة أفروسينا — دليل الرفع والتشغيل

## الملفات
- `index.html` — الصفحة كاملة (حجمها حوالي ٥٫٩ ميجا، أقل بكثير من حد ٢٥ ميجا)
- `config.js` — ضع فيه رابط الربط (Apps Script)
- `apps-script.gs` — كود جدول العملاء (Google Sheets)

## ١) الرفع على جيت هب
1. أنشئ مستودعاً (Repository) جديداً.
2. ارفع الملفات الثلاثة (`index.html` و`config.js` و`apps-script.gs`).
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)`.
4. رابط الصفحة سيكون `https://USERNAME.github.io/REPO/` ، وهو نفسه الذي يُنشأ منه الباركود تلقائياً.

## ٢) تفعيل تسجيل الزوار تلقائياً (مرة واحدة)
بدون هذه الخطوة تعمل الصفحة، لكن لن تظهر بيانات الزوار لك في الإدارة.
1. أنشئ Google Sheet جديداً ← Extensions ← Apps Script.
2. الصق محتوى `apps-script.gs` وغيّر `ADMIN_KEY` إلى كلمة سر طويلة.
3. Deploy ← New deployment ← النوع: Web app ← Execute as: **Me** ← Who has access: **Anyone** ← انسخ الرابط.
4. افتح `config.js` على جيت هب وضع الرابط في `api`.
5. في الصفحة: إدارة ← الأمان والربط ← اكتب نفس `ADMIN_KEY` في خانة «مفتاح الإدارة».

بعدها يسجَّل كل زائر (الاسم والهاتف وعدد الزيارات) في الجدول، ويظهر في «العملاء المسجلون».

## ٣) ما الذي يُرسل لواتساب ٠١٢٢٨٤٨٩٦٣٦؟
- عند دخول الزائر تُفتح له رسالة واتساب جاهزة للرقم (باسمه ورقمه) ويضغط «إرسال» بنفسه. هذه حدود واتساب: لا يمكن لصفحة ويب إرسال رسالة بدون ضغطة المستخدم.
- التسجيل الفعلي والموثوق يتم في الجدول تلقائياً حتى لو لم يضغط إرسال.
- اختياري: لتصلك رسالة واتساب تلقائية بكل زائر جديد، فعّل خدمة CallMeBot (راجع موقعهم للتفعيل) وضع مفتاحك في `CALLMEBOT_KEY` وأعد نشر السكربت.

## ٤) إشعار المنتجات الجديدة
إدارة ← «إشعار منتجات جديدة»: يجمع المنتجات الجديدة في **رسالة واحدة** قابلة للتعديل، ثم:
- «إرسال لكل الأرقام»: يفتح واتساب لكل رقم بالرسالة، وتضغط «إرسال» ثم «التالي».
- «مشاركة / قائمة بث» و«vCard للأرقام»: لإرسالها دفعة واحدة من واتساب نفسه عبر قائمة بث.
- الزوار العائدون يرون تلقائياً شريط «منتج جديد منذ زيارتك الأخيرة».
الإرسال الآلي الكامل لمئات الأرقام بدون أي ضغطة يحتاج واتساب بزنس API (مدفوع) وسيرفر.

## ٥) تعديل المنتجات ونشرها
التعديلات تُحفظ على جهازك. لتظهر للجميع: إدارة ← «تحميل الصفحة المحدّثة» ثم ارفع `index.html` الجديد مكان القديم. يمنعك الزر تلقائياً إن تجاوز الحجم ٢٥ ميجا. قاعدة بيانات العملاء لا تدخل داخل `index.html` أبداً.

## ٦) الأمان
- بيانات الدخول الحالية: المستخدم `angel` وكلمة المرور `8585` — غيّر كلمة المرور من «الأمان والربط». تُحفظ الآن مشفّرة (SHA-256) وليست نصاً صريحاً، لكن لوحة الإدارة تعمل داخل المتصفح فقط، فلا تعتمد عليها لحماية معلومات حساسة.
- قائمة العملاء محمية بـ `ADMIN_KEY` داخل Apps Script وليست في الصفحة.
